F1: The 11 — 문구 통합 / 사진 비교 / 전환 효과 수정본

1. 실행: index.html을 열면 됩니다. assets 폴더와 content.js를 같은 위치에 유지하세요.
2. 문구 수정: 폴더 최상위 content.js가 실제로 연결된 문구 파일입니다.
   각 항목의 '// 수정 위치:' 각주를 보고 따옴표 안의 글자를 수정하세요.
   화면의 문구 편집 → 문구 파일 저장으로 받은 파일도 이 content.js를 교체하면 됩니다.
3. F1-The-11.html은 CSS와 JS를 내장한 별도 HTML입니다. 이미지·영상용 assets 폴더는 필요합니다.
4. Overview에서 페이지별 실제 화면 사진을 수정 전후로 비교할 수 있습니다.
   사진 안에서 스크롤하거나 '사진 크게 보기'를 누르면 새 탭 없이 확대됩니다.
5. 오프닝 종료 / 전시 입장 / 건너뛰기 시 0.7초 페이드로 메인에 진입합니다.
   운영체제의 '동작 줄이기' 설정에서는 즉시 전환합니다.
6. user-submitted 폴더에는 사용자가 추가한 content.js와 index-edited.html 원본을 보존했습니다.
   최상위 index-edited.html도 제출본 그대로 보존했습니다. 최신 사이트는 index.html입니다.
7. before.html은 최초 제작본의 보존 기록입니다. revision.html은 사진 비교 화면입니다.
8. 이 사이트는 HTML/CSS/JavaScript로 실행되며 React나 Next.js 설치가 필요하지 않습니다.
