# F1: The 11

황성빈의 생성형 AI 디자인 기말 온라인 전시.

## 실행

`dist/index.html`을 브라우저로 열거나 이 프로젝트 폴더에서 `python3 -m http.server 4173 --directory dist`를 실행한 후 http://localhost:4173 으로 접속합니다.

HTML, CSS, JavaScript는 `dist/index.html` 한 파일에 포함되어 있습니다. 이미지, 영상과 폰트는 `dist/assets`에 있습니다. 원본 파일은 변경하지 않았으며 영문 이름으로 복사했습니다.

## 구성

- 오프닝 영상: 자동 무음 재생, 사운드 전환, 입장 및 건너뛰기
- 11개 팀 가로 갤러리: 드래그, 터치, 이전/다음 버튼, 작품 확대 대화상자
- Prompt Archive / Overview / Artist Profile / The Process
- 모바일 메뉴, 영상 플레이어, 수정 전후 비교

프롬프트 원문은 기획안에 비어 있어 미등록으로 표시했습니다. 11개 팀 합성 포스터는 최종 파일이 없어 기획 작품으로 표시했습니다. 팀 성적 데이터는 제공되지 않아 수치를 임의로 추가하지 않았습니다.
